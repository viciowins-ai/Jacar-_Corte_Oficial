## 🚀 COMO USAR

### Para o Cliente:
1. Acesse https://jacare-do-corte-app.vercel.app
2. Faça cadastro ou login
3. Escolha serviço, barbeiro, data e hora
4. Confirme o agendamento
5. Veja seus agendamentos no perfil

### Para o Dono:
1. Faça login com email de admin
2. Acesse "Painel do Dono"
3. Veja agendamentos e faturamento
4. Confirme presença ou cancele
5. Entre em contato via WhatsApp
